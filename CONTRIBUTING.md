# Участие в разработке

## Сборка

Нужен Rust из `rust-toolchain.toml` (1.97.1) с компонентами rustfmt и clippy.
`rustup` установит их автоматически при первом запуске cargo.

```sh
cargo build --workspace
```

`aws-lc-sys`, который использует rustls, может потребовать `cmake` и `perl`.
В Dockerfile они уже установлены.

## Тесты

```sh
cargo test --workspace
```

Unit-тесты лежат в модулях `#[cfg(test)]` рядом с кодом. Сквозные тесты —
`crates/elira/tests/proxy.rs`: они поднимают настоящий листенер и настоящий
upstream на реальных сокетах.

## Форматирование и clippy

```sh
cargo fmt --all
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
```

PR не принимается, если `fmt --check` или clippy с `-D warnings` падают.

## Стиль

Правила из `notes/STYLE.md`:

- имена короткие, но не короче смысла: `upstream`, `route`, `client`, `handler`;
- комментарий объясняет «почему», а не «что»; очевидную строку не комментируем;
- файл держим небольшим: одна причина для изменения;
- сначала простое решение, слой добавляем ко второму вызывающему;
- ошибка говорит, что делать, а не только где она случилась;
- без эмодзи и маркетинговых слов;
- код, комментарии и сообщения коммитов — по-английски.

Документация в репозитории — по-русски.

## Как добавить маршрут

1. Добавьте поля в структуры `Config`/`Route`/`Upstream` в
   `crates/elira-config/src/lib.rs` и проверки в `Config::validate`. Неизвестные
   поля и так отклоняются из-за `deny_unknown_fields`.
2. Добавьте unit-тест в конец `crates/elira-config/src/lib.rs`: валидный случай
   и отказ для неверного значения.
3. Для проксирования и выбора цели правьте `Proxy::new` и `Router` в
   `crates/elira-proxy/src/lib.rs`. Для статики — `crates/elira-proxy/src/files.rs`.
4. Если поведение видно снаружи, добавьте сквозной тест в
   `crates/elira/tests/proxy.rs`. Тест должен поднимать реальный сервер через
   `start`, а не копировать логику.
5. Обновите `docs/configuration.md` и, если уместно, пример в `examples/`.
6. Проверьте примеры:

```sh
cargo run -p elira -- check --config examples/static.toml
```

## Требования к PR

- Изменение посвящено одной задаче; форматирование и переименования не
  смешиваются с поведением.
- Есть тест на новое поведение и на ошибку, которую оно предотвращает.
- `cargo test --workspace`, `cargo fmt --all -- --check` и
  `cargo clippy --workspace --all-targets -- -D warnings` проходят локально.
- В описании сказано, что сломается без изменения и как это проверялось.
- Изменения в разборе заголовков, TLS, статике, `CONNECT` и rate limit явно
  отмечены как затрагивающие безопасность.
- Публичные ошибки и сообщения в логах остаются понятными оператору.
